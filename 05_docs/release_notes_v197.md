## 적용 방법

이 패치는 **차분 패치(xdelta)** 입니다. 원본 게임 데이터는 들어 있지 않습니다.
정품 디스크에서 뜬 이미지가 따로 있어야 합니다.

### 필요한 원본

| 항목 | 값 |
|---|---|
| 파일 | `Arc the Lad (Japan)` 단일 트랙 BIN/CUE |
| 크기 | 631,820,112 바이트 |
| SHA-1 | `67E6B53D3C7D229FBAAFB23E75DCD91520AE35A4` |
| MD5 | `219F45A30345D4A7370303576E312D8C` |

해시가 다르면 적용해도 실패합니다. 다른 립을 쓰신다면 알려 주세요.

### 순서

1. **xdelta UI** 같은 도구를 준비합니다.
2. 원본 `.bin` 을 고르고, 패치 파일 `arc1_kor_v197.xdelta` 를 고릅니다.
3. 출력 이름을 **`arc1_kor.bin`** 으로 합니다.
4. 같이 들어 있는 `arc1_kor.cue` 를 그 옆에 둡니다.
5. 에뮬레이터로 `arc1_kor.cue` 를 엽니다.

명령줄을 쓰신다면:

```
xdelta3 -d -s "원본.bin" arc1_kor_v197.xdelta arc1_kor.bin
```

## 오류가 날 만한 곳 — 여기를 봐 주세요

우선순위 순입니다. 위쪽일수록 제보가 도움이 됩니다.

### 1. 글자가 통째로 안 보인다

가장 중요합니다. 이 게임은 글자가 없으면 **에러 없이 그냥 빈칸으로 그립니다.**
그래서 지나가면 모릅니다.

지금까지 세 번 있었고 모두 고쳤습니다 — `○` 아이콘, `괜찮아`의 `괜`,
레벨업의 `상승`. 배포 전에 대사 2,847개를 전수 검사해 **남은 것은 0건**이지만,
검사가 닿지 않는 경로가 있을 수 있습니다.

> **말이 이상하게 끊기거나 한 글자만 빈칸이면 알려 주세요.**

### 2. 선택지 커서가 엉뚱한 줄을 가리킨다

질문이 길면 두 줄로 넘어가면서 아래가 밀립니다. 12곳 중 2곳에서 발견해
고쳤지만, **나머지는 실제로 확인하지 못했습니다.**

> **커서(▶)가 선택지와 어긋나 있으면 그 장면을 알려 주세요.**

### 3. 대사가 창 밖으로 넘친다

한국어가 일본어보다 길어지는 문장이 있습니다. 원본보다 줄이 늘어난 대사가
821개입니다. 원본이 쓰던 범위 안이라 계산상으로는 괜찮지만, 장면마다
창 크기가 달라서 잘릴 수 있습니다.

> **문장이 중간에 잘리거나 창을 뚫고 나오면 알려 주세요.**

### 4. 후반부

확인 작업이 **초반과 중반에 몰려 있습니다.** 후반부는 거의 눈으로 보지
못했습니다. 뒤로 갈수록 문제가 있을 확률이 높습니다.

### 5. 전투 중 화면

기술 범위 표시와 레벨업 문구를 최근에 고쳤습니다. 일부만 실기로
확인했습니다.

> **전투 중에 글자 조각이나 이상한 무늬가 보이면 알려 주세요.**
