아크더래드 1 한글 패치 v0.9.6 (V381) — 일본판 Rev 1 전용

V379에 누적한 수정입니다. 이전 물의 신전, UI, 선택 커서, 정령 명칭과 대사 수정도 포함합니다.

적용 방법
1. 일본판 Rev 1 원본 BIN에 동봉 xdelta를 적용하세요.
2. 출력 이름은 arc1_kor_v0.9.6.bin으로 지정하고 동봉 CUE를 옆에 두세요.
3. CUE로 새로 부팅하고 메모리카드 세이브를 불러오세요.
이전 한글패치 BIN에 덧씌우지 마세요. 이전 에뮬레이터 상태저장은 옛 메모리를 복원합니다.

원본 CRC32 {source_crc} / MD5 {source_md5}
목표 BIN SHA256 {target_sha}

수정 내용
- 왕을 부르는 대사의 '왕님'을 '전하'로 수정.
- 왕의 마지막 대사를 '형에게... 사과 한마디라도 하고 싶었다....'로 정리.
- 왕의 마지막 대사, 촌가라의 재촉, 아크의 무너진 계단 대사에 빠진 원본 대기 15개 복원.
- 수배 방송을 '범인은 토우빌 마을 출신 아크 에다 리코르누를 우두머리로 한 일당 7명으로,'로 수정.
- 깨진 L/R 버튼 그림을 일반 문자 'L R 대상변경'으로 수정.

검증
고정 V379에서 누적 재빌드, 기존 UI/물의 신전/선택 커서 회귀 검사.
새 상태 6개 출력 재현. 대기 3대사는 원본/수정전/수정후 실제 한 글자 출력 코드를 비교:
왕 11개, 촌가라 120·240회, 아크 60·240회 대기 카운터 일치.
디스크 멤버 readback/LBA/EDC/ECC, xdelta 적용 결과 및 반복 생성 일치.
