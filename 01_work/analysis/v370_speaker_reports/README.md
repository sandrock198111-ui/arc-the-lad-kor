## 반복 제보의 원인

- 현재 `화자:|` 형식 29건은 V364 build_report의 보류 29건과 집합이 완전히 같다. 새로 생긴 회귀가 아니라 미처리 잔여다.
- 29건은 연출 코드 16건, 선택문 12건, 길이 보류 1건이다. 이전 검사는 안전한 일반 본문에 한정하여 이들을 제외했다.
- 이전 검사는 콜론으로 끝나는 화자 뒤 줄바꿈을 찾았다. 콜론 자체가 없는 `병사|대사` 유형은 이 조건으로 잡히지 않는다.
- 원문 첫 줄 화자와 기존 한글 화자 대응으로 추가 검색한 콜론 없는 후보는 65건이다. 자동 수정 대상이나 확정 오류 수가 아니다.
- 이번 모집단은 역사적 추출 CSV 2878행이다. 실제 대사 여부가 잘못 추출된 행도 포함하므로 전체 게임 대사 2878건을 완전 검증했다고 표현하지 않는다.
- 말투는 라마다 승려라는 표시 이름만으로 일괄 변환하면 안 된다. 원문에도 반말형 퀴즈 승려와 정중한 수행 안내 대사가 있으며 같은 NPC/분기인지 추가 확인이 필요하다. 주변 #1736~1747 검토는 전체 게임 말투 검수가 아니다.
