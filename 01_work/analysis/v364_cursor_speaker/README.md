## 변경

V363을 보존한 26멤버(EXE+25DAT) 시험판. 원본 새 staging에 패치를 적용해 디스크를 생성했다. 기존 BIN은 비교에만 사용하며 빌드 입력이 아니다. 고정 V363 ZIP은 명시적 legacy 의존물이다.

선택 전용 함수0x8015A640의 고정7명령을 조정했다. 선택번호·기준행14배를16배로, X에14px 추가, Y 마지막-1을+2로 바꾼다. 열 간격12배, 선택 인덱스·항목수·입력/확정/취소 로직은 보존한다. 공유 triangle setter/draw, 진행안내 삼각형, 전투 범위 커서는 바꾸지 않는다. 새 코드 공간/훅/VRAM/폰트 변경 없음.

사용자 상태7/8의 예상 첫/둘째 커서 top은 (60,66)/(60,82), tip은 (67,72)/(67,88)로 글자Y64/80의 셀 중심과 일치한다. 가로 간격은 기존 큰 빈틈을14px 좁힌다. 실제 시각 중심과 사용자 취향 승인은 별도다.

기존 원문표의 화자개행 후보147 중 안전 조건을 통과한118건과 원문표 밖 승려 질문1건을 연결했다. 의미 문구를 고치지 않고 첫 `E6 01`을 동일2바이트의 공백 두 개로 교체한다. 기존 공백이 있으면 화면 간격은 두 칸보다 커질 수 있다. 이 시험판은 `화자`만 단독 행에 두는 강제개행을 제거하는 것이며 한 칸 띄어쓰기 정규화를 주장하지 않는다.

일반 대상은 특수 제어/선택 없는 스트림, 수정후64패킷 이하, 보수적228px/4행 모델 통과 조건이다. 모든 실제 E2 payload/skip를 따라 검사하며 주소/파일 길이/metadata/다른 제어를 유지한다. 원문표 밖0x4395A 질문은 개행 제거 후에도 자연wrap으로 질문영역2행을 유지하여 E5 선택행 위치를 보존한다. 질문 뒤 패딩으로 빈 줄이 보일 가능성을 실기로 확인해야 한다.

9번#1749 및 라마다의 도전 횟수 안내10건은 포함된다. 9번째 안내는 원래 연결돼 있어 변경하지 않는다.

## 검증

- 같은 입력 ZIP 재생성 byte exact. 고정 명령 assemble/disassemble/재assemble 확인.
- 독립 검사: EXE7위치/허용DAT범위/크기/문구 의미 토큰 동일성/변경스트림64한도/COMM동일 PASS. 기존 legacy 실패 증가 없음.
- 캡처 RAM에서 실제 커서 좌표 계산을 실행: 상/하단 원점×기준행0..3×선택0..3×열0..2×2캡처=192조건 PASS. 좌표 산식 검증이며 화면 밖 항목을 배치해도 좋다는 뜻이나 입력 끝처리 검증이 아니다.
- 디스크 data LBA506·멤버164 readback PASS, 전체507파일 extent/size동일. 변경raw69개+이전대응69개 EDC/ECC138검사 PASS. 선언한EXE/DAT/ISO timestamp외 변경0.
- CPU/GPU 전체 대화루프/새 개행의 실제 출력/입력 반복과 첫·마지막 항목 이동은 플레이 확인 대기. 상속 길이·번역·전수조사 부채 및29개개행보류가 남는다.
