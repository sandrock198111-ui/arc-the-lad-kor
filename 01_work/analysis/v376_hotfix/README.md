# V376 / v0.9.2 긴급 수정

사용자 2026-09-10 수정·빌드 지시에 따라 V375 배포본의 확정 결함을 수정했다. 원본, 기존 배포본, 사용자 세이브는 변경하지 않았다.

## 적용 범위

- 원문 추출이 이벤트 피연산자와 opcode를 대사로 오인한 24행을 원본 3바이트 단위로 복구. 9개 DAT에 적용하며 물의 신전 S8041 포함.
- 고겐/이가 및 다크 이름 ID 뒤바뀜을 포함한 공통 UI 102곳. 장비 41/42의 효과 설명을 맞바꾸는 수정은 하지 않았다. 원본 장비 소유자와 효과 연결은 정상이며 캐릭터 이름 표가 뒤바뀐 것이 제보의 원인이었다.
- 튜토리얼·선택지 70본문: 명칭 통일, 누락된 공격/방어/행동 질문, 참가자 이름 확인, 아이템 효과 확인 조작 조건 등. 활성 E5/E6의 물리 위치와 순서를 유지하고 검증된 E2 저장 슬롯만 사용했다.
- 오돈 명령 포인터, 스프라이트 texture descriptor, 효과음 ID, RGB 키 값 복구. 배우 88~90의 원본 기록을 복구하기 전에 해당 기록에 들어가 있던 UI 문자열 2개를 소유권 확인된 문자열 공간으로 옮겼다.
- 돈/딜 두 글자는 기존 텍스트 사용 0, packed lookup 참조 0, 비문자 접근 안전성이 확인된 물리 글꼴 765/816에만 추가했다. 다른 1,918개 plane은 동일하다.

## 검증과 한계

물의 신전 실제 VM 코드 CPU 검사: 원본과 동일하게 opcode 0B,0B,14,21 처리 후 return=1. 수정 전의 return=0과 구별된다. 배우 88 복사/refresh/dispatch도 원본과 동일한 status=0 경로이다.

설명창 154행/346조건, 전투 커서 1,152조건, 기존 V374/V375 선택지 및 카드 라벨 CPU 회귀 통과. 변경 대상 외 대사·DAT UI 3,490본문은 확장 토큰이 동일하다. 원문 확인 보류 DAT는 해당 원시 바이트 보존을 별도 검사하며 확장 검사 성공으로 세지 않는다.

전수 조사 범위는 UI 723행, DAT UI 868본문 및 추출 원문 2,878행이다. 조사 완료와 전 항목 해결은 다르다. **퀴즈 말투 29본문은 소유권이 확인된 저장 공간 부족으로 보류**, UI 6행/DAT 94행은 원문/소비자 확인이 남아 있다. 자세한 목록은 V375 전수 조사 폴더와 build_report.dat.held를 참조한다.

DuckStation 0.1-7126에서 새로 부팅하고 메모리카드에서 불러온 물의 신전 진입·전투·전체 플레이 검증은 아직 하지 않았다. 기존 상태저장은 옛 RAM을 복원하므로 수정 확인에 사용하면 안 된다. bible_current의 실화면 성공 기준을 V376으로 승격하지 않았다.
