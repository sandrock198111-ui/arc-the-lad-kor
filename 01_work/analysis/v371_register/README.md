모두 `맞나?`이며 원문은 참가자 이름+`さんですね。`. 최소 수정안 `맞습니까?`는 현행 글리프 누락0/6B로,14건 각각의 기존8B 질문 구간 안에 들어간다. 이는 정적 인코딩 예산 확인이며 삽입/커서/렌더 검증이 아니다.
