## 정령별 말투: 원문 비교 의견

원장의 9종 **화자명이 명시된 135행 전체**를 분류했다(spirit_voice_corpus.json). 초상화만 나오는 무기명 대사 전체를 이 숫자에 포함했다고 주장하지 않는다. 이번 SF041의 앞뒤 문맥은 contexts.json으로 별도 확인했다. 원문은 정령마다 말투가 다르므로 전원을 존댓말 또는 반말로 통일하면 성격 차이를 지운다.

## 누락 원인과 조사 범위

- 현재 패치에 포함된 **DAT 162개 전체**에서 원본의 `17 00 00 00` 뒤 텍스트 후보를 검색했다. 추출기의 payload_start는 argument0을 바로 앞 header29와 특정 관계일 때만 건너뛰어, 독립적인 argument0 대사를 누락했다.

- 실제 캡처 두 곳(2/6)이 argument0 뒤 본문·종료를 증명하며, 다른 보완 대사는 원본 토큰·문장 경계와 같은 형식의 명시적 목록을 사용했다. 모든 보완문의 출력은 실제 글자 코드로 검증했지만 각 장면의 이벤트를 처음부터 플레이한 것은 아니다.
