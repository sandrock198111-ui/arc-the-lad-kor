## 변환 규칙

1. 바로 인접한 두 영숫자/한글 글리프가 자동 개행으로 갈라지는 곳을 검출한다.
2. 해당 어절 앞의 A1 공백 하나를 E601 개행으로 교체하고 CPU로 다시 계산한다.
3. 기존 강제 개행은 유지한다. 공백/개행 이외의 모든 글자 코드 및 순서는 보존한다. 의미 축약·말투 교정은 하지 않는다.
4. 출력 행 범위가4행 이내이고 중간 빈행이 없어야 배치 후보로 센다. 단순 occupied Y 개수만 세지 않는다.
5. inline 후보는 늘어난 개행 바이트 수만큼 맨 뒤 A1 공백을 회수할 수 있을 때만 동일길이 후보로 분류하고 다시 CPU 출력/비공백 토큰 동일성을 검사한다. 원본 종료 NUL 위치를 바꾸는 재삽입은 하지 않는다.

기존 E6 양쪽이 실제 한 어절인지, 원래 공백 경계인지 구별할 근거가 없는 경우는 자동 병합하지 않는다. 따라서 `no_auto_split`은 모든 줄바꿈 문제가 없다는 판정이 아니다. 어절 자체가 창보다 길거나 안전한 앞 공백이 없으면 별도 실패한다.
