# 라마다사 퀴즈 전체 조사 — V366 기준, 수정 없음

## 결론

퀴즈는 질문29개/답안116개다. 입구의2지선다 두 창을 포함하면 선택창31개다.
관련 이벤트 텍스트107개(4395A..45E4F)를 기존 CSV 시작45000과 무관하게 열거했다.
기존 표에는63개가 없고, 현행 원문동일 미변환 본문은58개다.

|원문 미변환 부분|개수|범위|
|---|---:|---|
|질문|18|목록2~19번|
|네 항목 선택지 묶음|17|목록2~18번, 답안68개|
|질문 직후 정답/후속 대사|18|목록1~18번|
|그 밖의 보상/추가 설명|5|관련 대사 목록 참조|

따라서 이번 깨짐은 다음 문제에서 새로 손상된 것이 아니라, 첫 문제만
복구한 뒤 남은 같은 추출 누락을 계속 소비한 것이다. 19번은 질문이
45000 앞/선택지가45000 뒤라 질문만 깨지는 경계 사례다.

## 좌표·행·이동 조사

- 실제 V366 EXE와 사용자 V366 RAM 복사본에서107본문을 실제 렌더러로 실행.
  출력패킷수/종료포인터107개 일치, 최대47/64패킷, 네 행 초과0.
- 실제 이벤트 인자 reader와 선택 좌표 코드로31창/120선택 위치를 대조.
  각 선택지 첫 글자의 좌표와 커서 정렬 불일치0.
- 원래 E5들여쓰기는 글자X74/커서X60. V366의 첫 네선택창만
  글자X54/커서X36. 네선택창은 행Y32/48/64/80, 커서상단Y34/50/66/82.
- 첫 수행 질문은 선택지2/3행, 거절 뒤 질문은3/4행으로 시작한다.
- decoded-pad 상하 입력/끝 순환240조건 통과. 이는 실제 입력 장치나
  확정/취소/정답 결과의 게임 플레이 검증과는 구별한다.

**이 결과는 현재 데이터의 배치 검사다.** 원문이 깨진 채로도 합법적인
글리프 패킷과 좌표를 만들 수 있다. 원문 잔존을 정상 번역으로 세지 않았다.
한국어 복구 후에는 길이·들여쓰기·시작행을 재계산하고 같은107본문/31창을
다시 실행해야 한다. 공용 커서를 일괄 옮기는 방식은 해결책이 아니다.

대조했다. S6054의42000..EOF에서 같은 헤더를 쓰는 추가 네선택창은0개였다.

실플레이로 검증한 것은 아니다. 공통 오답/보상/소지중 안내도107본문에 포함했다.
